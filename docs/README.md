# eCDF Documentation

## Project role

eCDF is a **research prototype** for reproducible settlement experiments. It is not a currency, bank, payment service or production financial system.

## Documentation map

- [Project README](../README.md) — scope, commands, limitations and security constraints.
- [Project Status](PROJECT-STATUS.md) — evidence-based maturity snapshot.
- `architecture/` — technical architecture source of truth.
- Other records under `docs/` — research, ADR and prototype build records.

## Engineering baseline

The repository contains TypeScript source, tests, a pinned npm lockfile, a security policy and GitHub Actions verification.

## Documentation convention

Architecture describes intended structure. Tests and CI establish observed behavior. Claims about live Testnet, legal validity, CDF backing or production readiness must remain UNKNOWN until explicitly demonstrated.
